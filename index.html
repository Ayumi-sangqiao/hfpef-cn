BREATH₂：先筛查，再决定是否进一步评估

逐项核对病史、血液检查、胸片和心电图。年龄与利钠肽各占 2 分，其余各占 1 分。血红蛋白换算：13 g/dL = 130 g/L，12 g/dL = 120 g/L。BNP 与 NT-proBNP 只需任一项达到阈值，不重复加分。

总分原版转诊参考分级如何理解
0–3低仍需解释气促原因；持续怀疑时继续评估。
4–5中进一步超声及专科评估有价值。
6–7高优先考虑专科评估及客观证据确认。
8–9很高高度提示需进一步评估，不能只凭分数确诊。

HFpEF 的确诊仍需结合症状、保留的左室射血分数及充盈压升高等证据。贫血、房颤、肾功能异常、肺部疾病等也可能影响气促或评分项目；应结合完整临床资料解释。

ESE：必须按原研究的测量条件填写

  • LASr：左房储存期应变，不是左室 GLS，也不是左房收缩期应变；按原工具采用心尖四腔切面。20% 本身不加分。
  • E/e′：E 为二尖瓣口舒张早期血流速度，e′ 为室间隔侧瓣环舒张早期组织速度。用同一速度单位相除。13 本身不加分，不用侧壁值或双侧平均值替代。
  • B 线：评估运动前后在相同右肺 4 个位置的变化，不能只因静息已有 B 线就计分；原版要求恢复期出现或增加至少 1 条。记录不全或图像质量不足时，应先补充检查，不能按阴性计分。

原研究采用仰卧位功率自行车运动负荷。不能将普通静息 TTE、散步后的随意测量或药物负荷结果直接套入这套规则。规范采集由有经验的超声团队完成。

计算公式、概率对照与示例

设 p 为检验前概率的小数形式，如 50% = 0.50。LR 为相应 ESE 分级的似然比。

检验前优势比 = p / (1 - p) 检验后优势比 = 检验前优势比 × LR 检验后概率 = 检验后优势比 / (1 + 检验后优势比) 等价公式：检验后概率 = (p × LR) / (1 - p + p × LR)
教学示例：70 岁、利钠肽升高、贫血，其余四项均阴性：BREATH₂ = 2 + 2 + 1 = 5 分，对应原版估计 57%。若 LASr = 18%、运动室间隔侧 E/e′ = 14、恢复期无新增 B 线，ESE = 2 + 1 + 0 = 3 分，更新后概率约 94.9%。

另一例：检验前概率为 50% 时，ESE 0 分降至约 9.1%，ESE ≥3 分升至约 93.4%。若检验前概率已是 90%，即使 ESE 0 分，检验后仍约 47.4%。因此，“阴性”不等于“没有心衰”。

证据强度与适用边界

BREATH₂ 的主要建模队列有 622 人，外部验证队列 105 人；主要诊断依据为 HFA-PEFF 步骤 2–3，另有 79 人的运动右心导管亚组评估。它适合筛查，但不能据此声称每个概率都在所有人群中完成校准。

ESE 的诊断建模来自 81 人，其中 61 人为 HFpEF；诊断参照直接测得的血流动力学，AUC 为 0.90。另有 620 人队列用于预后关联评估，不能把它误称为 620 人的独立侵入性诊断验证。

本中文版重现公开工具的计算规则，未进行新的临床验证。来自日本研究与转诊人群的概率，推广到其他地区或不同患病率的人群时需要谨慎。两种模型串联得到的数字是辅助估计。
